## Planned project — React Issue Dashboard, Part A

Create one React + TypeScript training application using **synthetic tickets** and a local mock API. Implement:

- Issue list, search/filter, selection and details.
- Add/edit form with validation and visible outcomes.
- Loading, error, empty and refresh states.
- Clear component boundaries, typed props and state, callbacks, controlled inputs, and appropriate effects or custom hooks.
- One traceable user action from event handler through API response to rendered UI.
- One scoped AI-assisted change with independently reviewed diff and tests.

Styling is intentionally minimal; do not add a Tailwind or other styling curriculum. No client data, production credentials or live deployment.
