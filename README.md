## Run the projects

From the repository root with Node.js installed:

```sh
node day-03/cli/request-summary.mjs
PORT=4178 node day-04/request-explorer/server.mjs
```

Open `http://127.0.0.1:4178/` for the Request Explorer web interface.

Git branch and merge-conflict practice from Day 3 is preserved in repository history and documented in [Day 3 Git evidence](day-03/git-lab-evidence.md). All completed Week 1 work is published on `main`.
